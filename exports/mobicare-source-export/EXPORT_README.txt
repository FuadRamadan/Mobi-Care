MobiCare source export
======================

This folder contains the MobiCare monorepo source, configuration, API contracts,
database schema, application assets, attached project references, and scripts.

Included:
- Gateway web app
- Pharmacy Portal web app
- Expo mobile app
- API server
- Shared database, API client, API specification, and validation packages
- Root workspace configuration and lockfile
- Attached images and project reference documents

Intentionally omitted:
- node_modules and package-manager caches
- generated dist/build output
- TypeScript build-info caches
- .git metadata
- Replit Agent internal workspace metadata and local skill files
- Environment files, credentials, and secret values

Install dependencies with pnpm install, then use the package scripts and the
artifact workflows configured by the project.
